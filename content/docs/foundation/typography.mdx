Rakfound pairs **Geist Rounded** (`--font-sans`, `--font-heading`, `--font-brand`) for interface typography with **Geist Mono** (`--font-mono`) for code and technical metadata. Type tokens set size, line height, and weight together — apply the token on its own and pick color with `text-text-*` classes. Click any token pill to copy it.

## Title

Page and section headings. Titles use `-0.25px` letter spacing.

<TypographyGroup group="title" />

## Body

Interface text: labels, controls, table cells, and short copy. Body tokens inherit color.

<TypographyGroup group="body" />

## Paragraph

Long-form reading text, such as answers, callouts, and descriptions.
