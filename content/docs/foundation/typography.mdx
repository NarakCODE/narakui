NarakUI pairs **Geist Rounded** (`--font-sans`, `--font-heading`, `--font-brand`) for interface typography with **Geist Mono** (`--font-mono`) for code and technical metadata. Type tokens set size, line height, and weight together — apply the token on its own and pick color with `text-text-*` classes. Click any token pill to copy it.

## Title

Page and section headings with optical negative tracking (`-0.025em` to `-0.015em`). Use `text-title`, `text-title-small`, or `text-title-mini` with `font-normal`, `font-medium`, or `font-semibold`.

<TypographyGroup group="title" />

## Body

Interface text: labels, controls, table cells, and short copy. Uses `rem` sizing and optical positive tracking at smaller sizes (`+0.005em` on `mini`, `+0.01em` on `micro`). Body tokens inherit color.

<TypographyGroup group="body" />

## Paragraph

Long-form reading text, such as answers, callouts, and descriptions.
