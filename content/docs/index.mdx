### What is NarakUI?

NarakUI is the set of React components, design tokens, and icons that every NarakUI product is built from. Components are written in TypeScript, styled with Tailwind CSS on top of the color and type tokens, and built on Radix primitives where a component needs focus management or keyboard support.

Each component page shows live examples, the code behind them, and the props the component accepts.

### Why this site is public

NarakUI is the design system behind our products. It lives inside our codebase and is shared through the `@narakui` registry so teams and builders can inspect and reuse it directly.

We keep this site public anyway. It's the reference and documentation our team works from every day, and a look at how we approach design: the decisions, the details, and the craft that go into what we build.

### Getting Started

NarakUI components are published through the public `@narakui` shadcn registry at `https://ui.narakcode.dev/r/{name}.json`. Add the registry to your `components.json` to install components with the shadcn CLI, copy the AI prompt on any component page, or copy the source files directly.

```json title="components.json"
{
  "registries": {
    "@narakui": "https://ui.narakcode.dev/r/{name}.json"
  }
}
```

Once configured, install any component using the shadcn CLI:

```bash
npx shadcn@latest add @narakui/button
```
