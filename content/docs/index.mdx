## What is Rakfound?

Rakfound is the set of React components, semantic design tokens, and icons that every Rakfound interface is built from. Components are written in TypeScript, styled with Tailwind CSS v4 on top of our light and warm-dark color and typography tokens (`app/design-system.css`), and built on Radix UI and `cmdk` primitives wherever a component needs accessible focus management or keyboard navigation.

Each component page shows live interactive examples, the source code behind them, and the complete props the component accepts.

## Why this site is public

Rakfound lives directly inside our codebase and isn't published as a public package yet. We keep this site open anyway — it's the live reference our team works from every day, and a window into how we approach interface craft: semantic surfaces, concentric geometry, tactile press feedback, and restrained motion.
