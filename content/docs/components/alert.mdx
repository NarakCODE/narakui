## Variants

`warning` and `destructive` render with `role="alert"`; `default` and `success` render with `role="status"`. Pass `role` to override. `default` uses the secondary background, so place it on a primary surface such as a card, dialog, or page.

## Alert Properties

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `variant` | `'default' \| 'warning' \| 'destructive' \| 'success'` | `'default'` | Surface tint and icon color. `AlertIcon` inherits it. |
| `role` | `string` | — | Overrides the live-region role chosen from the variant. |
| `className` | `string` | — | Additional classes for the container. |

## AlertIcon Properties

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `variant` | `'default' \| 'warning' \| 'destructive' \| 'success'` | — | Overrides the icon tint from the enclosing `Alert`. |
