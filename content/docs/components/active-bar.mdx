## Example

Place it inside a `relative` list that sets `--item-height`. Move it by changing `top`; the bar animates between items.

## Usage

```tsx
import { ActiveBar } from '@/components/ui/active-bar';
```

```tsx title="components/nav-list.tsx"
<nav className="relative flex flex-col [--item-height:32px]">
  <ActiveBar top={activeIndex * 32} />
</nav>
```

## Properties

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `top` | `number` | Required | Vertical offset in pixels of the active item. |
| `leftOffset` | `number` | `0` | Inset from the left edge in pixels. |
| `rightOffset` | `number` | `0` | Inset from the right edge in pixels. |
| `className` | `string` | `—` | Additional classes, for example a z-index or custom transition. |
