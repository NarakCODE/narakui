## Circular Progress

Circular progress indicators are suited for compact spaces and percentage completion.

### Sizes

`sm` (14px), `md` (20px, the default), and `lg` (60px), or pass any explicit pixel number.

### Animated

Pass `animated` to draw the arc from empty to its value when it first appears. Later value changes keep the regular transition. People who prefer reduced motion see the final value right away.

`trackColor` and `progressColor` take a CSS color. Use theme variables such as `var(--color-fill-blue)` so the colors follow light and dark mode.

## Usage

Both components clamp the value to `0`–`100`. `LinearProgress` is always exposed as a progress bar and is named `"Progress"` unless you pass `label`. `CircularProgress` is hidden from assistive technology unless you pass `label`.

```tsx
import { CircularProgress, LinearProgress } from '@/components/ui/progress-bar';

<LinearProgress value={50} />
<CircularProgress progress={50} size="lg" />
```

## LinearProgress Properties

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` (Required unless `indeterminate`) | `number` | `—` | Progress value from 0 to 100. Required unless `indeterminate` is set |
| `indeterminate` | `boolean` | `false` | Shows an animated bar instead of a value. Cannot be combined with `value` |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Height of the bar |
| `fill` | `string` | `'bg-fill-primary'` | Fill color class for the bar |
| `label` | `string` | `'Progress'` | Accessible name for the progress bar |
| `className` | `string` | `—` | Additional CSS classes for the outer wrapper |

## CircularProgress Properties

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `progress` | `number` | `0` | Progress value from 0 to 100 |
| `size` | `'sm' \| 'md' \| 'lg' \| number` | `'md'` | Named size variant (14, 20, or 60px) or an explicit pixel size |
| `label` | `string` | `—` | Accessible name. When set, the indicator is exposed as a progress bar |
| `strokeWidth` | `number` | `—` | Width of the stroke. Defaults to the size variant's stroke, or a tenth of a numeric size |
| `strokeLinecap` | `'butt' \| 'round'` | `—` | Shape of the arc ends. Defaults to `butt` for `sm` and `round` otherwise |
| `trackColor` | `string` | `'var(--color-fill-tertiary)'` | Color of the background track |
| `progressColor` | `string` | `'var(--color-fill-primary)'` | Color of the progress arc |
| `bgClassName` | `string` | `—` | Class applied to the background track |
| `fgClassName` | `string` | `—` | Class applied to the progress arc |
| `animated` | `boolean` | `false` | Draws the arc from empty to its value when it first appears |
