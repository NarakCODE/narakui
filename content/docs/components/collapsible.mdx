## Usage

```tsx
import { Button } from '@/components/ui/button';
import { Collapsible } from '@/components/ui/collapsible';

<Collapsible.Root>
  <Collapsible.Trigger asChild>
    <Button iconEnd="chevron-down">Toggle content</Button>
  </Collapsible.Trigger>
  <Collapsible.Content>Content to collapse/expand</Collapsible.Content>
</Collapsible.Root>
```

Without `asChild`, `Collapsible.Trigger` renders its own ghost text button and wraps the children in a `span`.

## Collapsible.Root Properties

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `defaultOpen` | `boolean` | `false` | Whether the collapsible is open by default |
| `open` | `boolean` | `—` | Controlled open state |
| `onOpenChange` | `(open: boolean) => void` | `—` | Callback when open state changes |
| `disabled` | `boolean` | `false` | Whether the collapsible is disabled |
| `className` | `string` | `—` | Additional CSS classes for the root element |

## Collapsible.Trigger Properties

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `asChild` | `boolean` | `false` | Merges trigger behavior into the single child, usually a `Button`, instead of rendering the default ghost trigger |
| `showHoverBackground` | `boolean` | `true` | Shows the hover background on the default trigger. Ignored with `asChild`. |
| `spanClassName` | `string` | `—` | Additional classes for the inner span of the default trigger. Ignored with `asChild`. |
| `className` | `string` | `—` | Additional CSS classes for the trigger |

## Collapsible.Content Properties

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `forceMount` | `true` | `—` | Keeps the content mounted while closed |
| `className` | `string` | `—` | Additional CSS classes for the content |
