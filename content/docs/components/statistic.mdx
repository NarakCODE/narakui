## Types

`number` abbreviates values of 1,000 or more with `k`, `M`, or `b`. `percentage` multiplies the value by 100, so pass a fraction.

## Trends

With `showTrend` on (the default), the sign of `value` sets the trend. Positive values are green with a plus sign, negative values are red with a minus sign, and values that round to zero show a dash.

</ComponentPreview>

## Rank changes

Set `changeMode` to `rank` to show an up or down arrow instead of a sign.

## Prefix and suffix

Add prefixes and suffixes to provide context for your statistics. With `showTrend` on, the plus or minus sign replaces the prefix, so turn it off for values like currency. Without a trend the value renders as an absolute number, so pass the sign in `prefix` when it matters, for example `prefix="-$"`.

## Usage

```tsx
import { Statistic } from '@/components/ui/statistic';

<Statistic value={0.042} type="percentage" />
<Statistic value={45_678} prefix="$" showTrend={false} />
```

## Properties

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `number \| null \| undefined` | Required | The numerical value to display. `null` or `undefined` shows `emptyText`. |
| `type` | `'number' \| 'percentage'` | `'number'` | `number` abbreviates large values with `k`, `M`, or `b`. `percentage` multiplies the value by 100 and adds `%`. |
| `showTrend` | `boolean` | `true` | Colors the value by its sign and adds a plus or minus sign, or an arrow in rank mode. Values that round to zero show a dash. When off, the value renders as an absolute number. |
| `changeMode` | `'value' \| 'rank'` | `'value'` | `value` shows a plus or minus sign. `rank` shows an up or down arrow and keeps the prefix. |
| `decimals` | `number` | `1` | Maximum number of decimal places to display. |
| `fixedDecimals` | `boolean` | `false` | Always shows exactly `decimals` fraction digits, keeping trailing zeros. |
| `disableFormatting` | `boolean` | `false` | Shows the full number without `k`, `M`, or `b` abbreviation. |
| `emptyText` | `string` | `'n/a'` | Text to display when `value` is `null` or `undefined`. |
| `prefix` | `string` | `—` | Text to prepend before the value. Replaced by the plus or minus sign when `showTrend` is on and `changeMode` is `value`. |
| `suffix` | `string` | `—` | Text to append after the value. |
| `animated` | `boolean` | `true` | Whether to animate value changes. |
| `transformDuration` | `number` | `250` | Duration of the digit animation in milliseconds. |
| `className` | `string` | `—` | Additional CSS classes for the wrapper and the value. Replaces the default `font-medium tabular-nums` value styling. |
