## Default player

This player uses the default skin with a title, a description, and chapters. Hover the timeline to see the chapter under the pointer, and open the settings menu to change quality, speed, captions, or Picture-in-Picture. To play audio in a single control bar, use the [Audio Player](/docs/components/audio-player).

## How the pieces fit together

A player has three required parts: the player, the skin, and the media. Each part has one job and nests inside the part above it, so you can change one without touching the others.

```tsx
import { Title, Video, VideoPlayer, VideoSkin } from '@/components/ui/video-player';

<VideoPlayer title="Demo video" poster={posterUrl}>
  <VideoSkin className="aspect-video w-full">
    <Video src={videoUrl} playsInline />
    <Title description="Optional subtitle line." />
  </VideoSkin>
</VideoPlayer>;
```

| Part | Component | What it owns |
| --- | --- | --- |
| Player | `VideoPlayer` | Playback state for everything inside it. Takes `title` and `poster`, renders no UI. |
| Skin | `VideoSkin` | The interface: control bar, poster, loading and error states, shortcuts, gestures. |
| Media | `Video`, `YouTubeVideo`, `HlsJsVideo`, `MuxVideo` | The source. Renders the media element (or YouTube IFrame bridge) and nothing else. |
| Tracks | `ChaptersTrack` | Extra data for the media. Render it as a child of the media. |
| Additions | `Title`, `TimedSlot`, `UpNext`, `UserPreferences` | Optional overlays and behavior. Render them inside the skin. |

Any component inside the player can read playback state with `usePlayer`, even outside the skin:

```tsx
import { selectTime, usePlayer } from '@/components/ui/video-player';

const currentTime = usePlayer((state) => selectTime(state)?.currentTime);
```

## Show video details

### Poster

The poster is the image the player shows before playback. Set `poster` on `VideoPlayer`, not on the media, to use your own image. Pass `renderPoster` to `VideoSkin` to render a custom image component such as `next/image`.

Set `title` on `VideoPlayer`, then render `Title` inside `VideoSkin` to show it. `Title` takes an optional `description` for a second line, which hides on players narrower than 448px.

## Timed overlays and Up next

`TimedSlot` renders its children over the video during a `[start, end]` range (negative values count back from the end). Bottom slots lift automatically while the control bar is visible. `UpNext` builds on `TimedSlot` to present the next item before playback finishes.

## Keyboard shortcuts and gestures

Shortcuts are active while focus is inside the player so multiple players on one page never compete for keys.

| Keys | Action |
| --- | --- |
| `Space`, `K` | Play or pause |
| `←` `→`, `J` `L` | Seek 10 seconds |
| `↑` `↓` | Change the volume |
| `M` | Mute |
| `0`–`9` | Jump to 0% through 90% |
| `Home`, `End` | Jump to the start or the end |
| `<`, `>` | Play slower or faster |
| `C` | Toggle captions |
| `F` | Toggle fullscreen |
| `I` | Toggle Picture-in-Picture |

Click plays or pauses; double-click seeks 10 seconds in the left or right third and toggles fullscreen in the center third.

## Reference

### VideoPlayer

| Prop | Type | Description |
| --- | --- | --- |
| `title` | `string \| null` | The title of the video |
| `poster` | `string \| null` | The image shown before playback. Replaces any poster the media generates |

### VideoSkin

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `className` | `string` | `—` | Sizes the player, for example `aspect-video w-full` |
| `controls` | `ReactNode \| null` | `<DefaultVideoControls />` | Replaces the default control bar. `null` removes it |
| `locale` | `string` | Page language | Language of labels, tooltips, and RTL direction |
| `renderPoster` | `(props, state) => ReactNode` | `—` | Custom renderer for the poster image |

### Title

| Prop | Type | Description |
| --- | --- | --- |
| `description` | `ReactNode` | Second line under the title (hidden below 448px) |
| `visibility` | `'inline' \| 'fullscreen'` | Restricts the title overlay to inline or fullscreen mode |
| `className` | `string` | Additional classes for the title overlay |

### ChaptersTrack

| Prop | Type | Description |
| --- | --- | --- |
| `chapters` | `{ startTime: number; title: string }[]` | **Required.** Start times in seconds from the start of the media |

### TimedSlot

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `start` | `number` | `0` | Start time in seconds (negative counts back from end) |
| `end` | `number` | Video end | End time in seconds (negative counts back from end) |
| `open` | `boolean` | `true` | Hides the slot inside its range when `false` |
| `placement` | `'bottom-end' \| 'bottom-start' \| 'top-end' \| 'top-start'` | `'bottom-end'` | Corner placement inside the player |
| `transitionIn` | `'slide' \| 'fade' \| 'scale' \| 'none'` | `'slide'` | Entrance transition style |
| `transitionOut` | `'slide' \| 'fade' \| 'scale' \| 'none'` | Same as `transitionIn` | Exit transition style |

### UpNext

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `title` | `ReactNode` | `—` | Title of the next video |
| `description` | `ReactNode` | `—` | Short description (hidden below 512px) |
| `label` | `ReactNode` | Translated “Up next” | Eyebrow label above the title |
| `thumbnailSrc` | `string` | `—` | Preview thumbnail or animated GIF (hidden below 448px) |
| `href` | `string` | `—` | Makes the card a link instead of a button |
| `seconds` | `number` | `10` | Seconds before the end when the card appears |
| `onSelect` | `() => void` | `—` | Called when the viewer clicks the card |
| `onComplete` | `() => void` | `—` | Called when the media ends unless dismissed |
