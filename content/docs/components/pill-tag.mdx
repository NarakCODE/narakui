## Pill

A single line of text with a predefined text color. It has no background and a fixed height.

### Basic

Leave `color` unset to inherit the surrounding text color.

## Tag

A rounded container for categorizing, labeling, or highlighting content. It has no color of its own; set background and text colors with `className`.

### Basic

A neutral fill and an outline. Product tags use `text-body-mini-regular`.

<ComponentPreview file="components/examples/pill-tag-tag-basic.tsx">
  <TagBasic />
</ComponentPreview>

### Colors

Pair a muted `bg-bg-*` fill with the matching `text-text-*` color.

## Usage

```tsx
import { Pill, Tag } from '@/components/ui/pill-tag';

// Pill usage
<Pill value="Cited" color="green" />
<Pill value="Draft" withPadding={false} />

// Tag usage
<Tag className="bg-bg-orange text-body-mini-regular text-text-orange">Disabled</Tag>
<Tag className="border border-fill-quaternary text-body-mini-regular text-text-primary">
  Product page
</Tag>
```

## Pill Properties

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string` | Required | The text content to display in the pill. |
| `className` | `string` | `—` | Additional CSS classes to apply to the pill container. |
| `color` | `'green' \| 'blue' \| 'purple' \| 'orange' \| 'red' \| 'gray'` | `—` | Text color of the pill. Inherits the surrounding text color when unset. |
| `withPadding` | `boolean` | `true` | Whether to include horizontal padding in the pill. |

## Tag Properties

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `children` | `ReactNode` | Required | The content to display inside the tag. |
| `className` | `string` | `—` | Additional CSS classes to apply to the tag, including its colors. |
