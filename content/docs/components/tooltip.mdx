## Basic

A tooltip opens when its trigger is hovered or focused. Icon-only buttons need an `aria-label` as well; the tooltip does not name the button. Every `Tooltip` needs a `TooltipProvider` above it; render one near the root of the app.

## Delay

`TooltipProvider` sets the delay for every tooltip inside it. `delayDuration` is the wait before a tooltip opens, 300ms by default. `skipDelayDuration` is how long after one tooltip closes the next one opens at once, 500ms by default. This preview nests a provider with a longer `delayDuration`: the first tooltip in the toolbar waits 900ms, then moving to a neighbor opens it at once. One provider at the app root is usually enough.

## Usage

```tsx
import { Button } from '@/components/ui/button';
import { Tooltip, TooltipProvider } from '@/components/ui/tooltip';

<TooltipProvider>
  <Tooltip content="Runs all 128 prompts again">
    <Button iconStart="refresh">Rerun report</Button>
  </Tooltip>
</TooltipProvider>;
```

## Properties

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `content` | `ReactNode` | `—` | **Required.** The content to display in the tooltip |
| `children` | `ReactNode` | `—` | **Required.** The element that triggers the tooltip |
| `contentProps` | `TooltipContentProps` | `—` | Props for the Radix tooltip content. `className` applies to the tooltip surface |
| `rootProps` | `TooltipProps` | `—` | Props for the Radix tooltip root, such as `open` and `onOpenChange` |
| `side` | `'top' \| 'right' \| 'bottom' \| 'left'` | `'top'` | Preferred side of the trigger to render against |
| `disabled` | `boolean` | `false` | Whether the tooltip is disabled |
| `showArrow` | `boolean` | `false` | Whether to show an arrow pointing to the trigger element |
| `underline` | `boolean` | `false` | Whether to show a dotted underline beneath the trigger text |
| `focusableTrigger` | `boolean` | `false` | Makes the trigger keyboard-focusable and adds a focus outline, for triggers such as plain text |

## TooltipProvider

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `delayDuration` | `number` | `300` | Milliseconds before a tooltip opens on hover |
| `skipDelayDuration` | `number` | `500` | Milliseconds after a tooltip closes during which the next tooltip opens without a delay |
| `children` | `ReactNode` | `—` | **Required.** The tooltips that share these settings |
